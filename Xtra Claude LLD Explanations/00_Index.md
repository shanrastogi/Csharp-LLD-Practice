# Low Level Design (LLD) – SSE Interview Preparation

## Structure of Each LLD Answer

Each file follows this template:

1. **Interview Approach** — How to start, what to clarify, how to structure the discussion
2. **Requirements & Assumptions** — Functional and non-functional scope
3. **Core Entities** — Classes, enums, value objects
4. **Class Relationship Diagram** — Mermaid UML
5. **DB Schema** — Tables, columns, constraints, indexes
6. **Design Patterns Applied** — Which pattern, where, and why
7. **SOLID Principles** — How each principle is satisfied
8. **C# Implementation** — Interfaces, classes, key methods

## Common Interview Tip

> **Golden Rule**: Start with requirements → entities → relationships → DB schema → code → patterns → SOLID. Never jump to code first. Show you think before you code.
